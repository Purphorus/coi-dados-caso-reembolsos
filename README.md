# Caso: Central de Reembolsos

Caso da Aula 1 do **COI de Dados**.

[![Abrir no Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Purphorus/coi-dados-caso-reembolsos/blob/main/Caso_Reembolsos_inicio.ipynb)

A diretora financeira do Grupo Meridiano (fictício) pergunta:
1. Qual é hoje o prazo médio de um reembolso?
2. Se ela contratar mais um analista (hoje são 4; R$ 6.500/mês), quanto esse prazo cai? Vale a pena?

| arquivo | o que é |
|---|---|
| `briefing.md` | o pedido da diretora |
| `log_reembolsos.csv` | o log do portal de reembolsos (separador `;`, datas dd/mm/aaaa) |
| `dicionario_codigos.xlsx` | o dicionário de códigos do portal |
| `quadro_pessoal.xlsx` | a equipe da Central |
| `fluxograma_central.png` | o fluxo do processo, desenhado pela diretoria |
| `Caso_Reembolsos_inicio.ipynb` | ponto de partida: carrega os arquivos e mostra um pedido |

Os dados são sintéticos: nenhuma pessoa ou empresa real.
